# Control Library

Control objectives, existing control baseline, Microsoft overlap and AI-specific gaps.

The [AI Security Control Objectives Library](03_AI_Security_Control_Objectives_Library.md) holds 40 controls in 11 families. Each has an ID, `AI-CTRL-001` to `AI-CTRL-040`, that the risk mapping, domain standards, audit checklist and test case library use to refer to it.
